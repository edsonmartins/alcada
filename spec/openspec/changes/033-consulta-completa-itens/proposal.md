# Proposal — 033 consulta completa de itens

## Problema

O usuário consegue agir sobre a fila atual, mas não localizar com rapidez uma decisão fechada,
delegada ou originada em outro contexto.

## Resultado

Uma consulta única encontra estado e história, com filtros fixos e fontes navegáveis, sem criar uma
segunda fila operacional.

## Não objetivos

- editar, priorizar ou reorganizar itens;
- salvar visões ou taxonomias;
- gerar SQL ou resposta sem fonte por modelo.
