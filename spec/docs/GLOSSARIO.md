# Glossário (linguagem ubíqua)

| Termo | Definição | Não confundir com |
|---|---|---|
| **Pendência** | algo que espera uma decisão do gestor | tarefa, ticket, chamado |
| **Classe** | DECISAO, BLOQUEIO ou ESTEIRA — define roteamento padrão | categoria, tag |
| **Horizonte** | HOJE, SEMANA ou TRIMESTRE | prazo |
| **Saída** | uma das quatro: Resolver, Repassar, Reservar, Repousar | status |
| **Adiamento** | ação de primeira classe com data e motivo declarado | snooze silencioso |
| **Nível** | N1, N2 ou N3 — contrato de autonomia da delegação | permissão de sistema |
| **Janela de reversibilidade** | período após o prazo em que nada sai para fora | prazo |
| **Escalonamento** | subida ao gestor por silêncio de ambos os lados | vencimento |
| **Temperatura** | número de cobranças distintas deduplicadas | prioridade |
| **Regra de autonomia** | regra que decide uma classe inteira, não um item | aprovação |
| **Esteira** | processo repetido com portões fixos | workflow genérico |
| **Instância** | uma entidade externa percorrendo a esteira | pendência |
| **Bloco de decisão** | sessão agendada com dossiê para item que só o gestor decide | reunião |
| **Dossiê** | contexto agregado e ancorado, montado antes do bloco | resumo |
| **Trilha** | registro append-only de tudo que aconteceu | log |
| **Encolhimento** | queda mensal do nº de itens que dependem do gestor | throughput |
